# Loop 3 scratch archive

A copy of the parts of `scratch/loop3/` and `scratch/reprove/` (which git ignores) worth
keeping from the unattended loop of 2026-11-11 to 2026-11-13: every agent's `notes.md`
and other Markdown, the coordinator's `agents.txt`, `coordinator-rulings.txt` and
`CLAIMS.txt`, the agents' top-level scripts (`*.py`, `*.sh`, not copies of
`research/tools/`), work lists (`*.tsv`), and the probe sources the tricks file cites
(`buddy/p`, `dtor1/p`, `late2b/toy`, `opswap/v`, `rank1/p`, `zero1/p`).

Build outputs, logs, variant grids and Dolphin captures were left out. A path
`scratch/loop3/X/...` in the notes maps to `loop3/X/...` here. The scripts were written
for the shared checkout and may expect files under `scratch/`; read them for their
method before running them.
