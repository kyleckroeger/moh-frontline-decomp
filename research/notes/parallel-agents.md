On 2026-10-23 the user wanted to spend spare weekly usage on several agents at once. Setup: 4 background general-purpose agents (lines, parks, soldier, bigfiles) share the MAIN checkout (no worktrees: scratch tools hardcode <repo>, and scratch/orig/build are git-ignored). Rules are in scratch/par/PROTOCOL.md: draft only in scratch/par/<name>/; touch config/src/docs/build, or run port_unit/land.sh/one_unit/try.sh, only while holding `sh scratch/par/lock.sh acquire|release <name>` (mkdir lock at scratch/par/LANDLOCK); permuter max 2 jobs; agents append Log lines and the coordinator refreshes the AUTOPILOT header.

**Why:** worktrees would break the hardcoded paths; land.sh does `git add -A src config ...`, so landings must be serialized.
**How to apply:** if a session dies, check for a stale scratch/par/LANDLOCK and stray uncommitted files before restarting agents. Related: [[autopilot-loop]], [[oom-guard]]
