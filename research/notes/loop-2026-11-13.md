## Compiler rules found today

Full text with probes in [`loop3-tricks-2026-11-12.md`](loop3-tricks-2026-11-12.md)
(sections late1 to split2).

1. **Partial struct scalarisation** (buddy): CW 1.3.2 scalarises a struct member by
   member; a sub-struct read as a whole before the typed writes stays in the stack slot,
   the rest go to registers. Accepted spelling: an empty by-value inline,
   `inline void Check(BuddyState) {}` / `Check(state);`. A typed `operator=` is needed.
2. **Strength-reduced induction variables** (late2c, csweep): a counter stepped by a
   constant beside the loop index is the compiler's `i * K`; write the product
   (SNDI_precalcaztospkrvol 79 -> 4, CPartBin::Link 33 -> 4).
3. **Index, don't walk** a pointer whose first element loads through the base (late2c).
4. **Helper arguments evaluate right to left**: passing two wrongly coloured terms to an
   inline helper fixes their creation order (late2c).
5. **Commutative operand order** (rules2): lighter operand first (plain value, then
   expression, then call result); two plain values keep source order. A sweep over all
   drafts (opswap) found the drafts already follow it almost everywhere.
6. **Split into the destination** (opswap): `v = L; v op= R;` computes in v's register
   and changes colouring; member/array/return/chain splits are mostly inert (split2).
7. **Loop-derived pointers rank below parameters** for callee registers (rules2).
8. **One-declaration move sweep first** (late1): move each local to every slot, about
   n^2 compiles; with landed copies of shared inlines, start from their declaration order
   (split2: PATHI_eventstart 191 -> 160 and three others).
9. **`.c` drafts**: score with `SUFFIX=c` only for units without `-lang c++` (TRK);
   EA's `.c` files compile as C++ (csweep).
10. **Colour stack-word rule** (late2): a colour stored as one word and read back by
    bytes in a non-member order comes from an inline that copies the word into an
    integer local and casts it back (CFontDriver::EndDraw).
11. **Stack slots of a copy chain** are handed out from the frame top in creation order;
    a by-value inline's return temporary is created after the declared locals (csweep).
12. **Dead-stripping in the link model** (undef): references made only from a unit's
    discarded functions are `stripped`, not undefined (`source_link.py`).
